# 雨果跨境与网经社直采设计

## 背景

机器人需要在不依赖 GDELT 的情况下补充跨境行业媒体信息。2026-07-27 的低频现场检查显示：

- `https://www.cifnews.com/` 与其 `robots.txt` 均返回 HTTP 200，公开首页包含近期文章；
- `https://cbec.100ec.cn/` 返回 HTTP 200，但响应是公开 JavaScript 安全检查页；
- 网经社自己的静态跨境栏目 `https://imgs-b2b.100ec.cn/list--3--1.html` 与公开文章页直接返回 HTTP 200，不需要执行安全检查脚本；
- 本项目已经具备 HTML 采集、浏览器采集、安全 URL 校验、正文抽取、内容分级、AI 分析和来源失败隔离能力。

本次只接入用户指定的雨果跨境与网经社跨境电商台，不扩大至亿恩网、出海网或电商报，也不改变原有十个平台范围。

## 目标

1. 直接发现并采集两个媒体的公开文章，不把 GDELT 当作前置依赖；
2. 只让与 Amazon、TEMU、SHEIN、AliExpress、Shopee、eBay、Coupang、Ozon、Joybuy、TikTok Shop 有关的材料进入日报分析；
3. 在允许访问的公开文章上提取正文，交给 AI 生成通俗总结、风险等级、置信度、判断依据和建议动作；
4. 飞书卡片只展示分析结果、必要短摘和原文链接，不转载完整文章；
5. 任一媒体失败时安全降级，不阻断其他来源采集或每日推送。

## 非目标

- 不绕过验证码、登录、付费墙、访问控制或明确的自动化禁止；
- 不采集会员内容、评论、用户资料、课程、直播或下载资料；
- 不把媒体报道冒充平台官方公告；
- 不改变每日 09:00 推送计划；
- 不启用与这两个媒体无关的新平台或新媒体。

## 方案选择

### 采用：双站 HTML 直采

- 雨果跨境使用轻量 HTML 采集器访问公开首页和文章页；
- 网经社使用轻量 HTML 采集器访问其官方静态跨境栏目和文章页；
- 两者共用正文抽取、内容过滤、AI 分析和失败隔离链路。

该方案比“只保存标题和链接”能给 AI 足够上下文，也避免了启动本地浏览器和处理安全检查 Cookie。

### 未采用：纯元数据

只采集标题和链接最稳定，但不足以支持可靠的风险判断、判断依据和通俗解释。

### 未采用：浏览器采集

浏览器可以执行 `cbec.100ec.cn` 的第一方安全检查脚本，但会增加本机内存、启动时间和定时任务故障面。既然网经社提供可直接访问的官方静态栏目，就不应使用浏览器处理安全检查页。

## 架构与数据流

```text
雨果公开首页 ──HTML──┐
                    ├─> 同站文章候选过滤 ─> 详情页正文 ─> 十平台相关性过滤
网经社静态栏目 ─HTML──┘                                      │
                                                            v
                                             AI 通俗分析与证据分级
                                                            │
                                                            v
                                           飞书摘要卡片 + 原文链接
```

GDELT 保持独立的可选发现来源。它返回 429 或不可用时，不影响上述直采链路。

## 来源配置

### 雨果跨境

- 来源标识：`media-cifnews-cross-border`
- 入口：`https://www.cifnews.com/`
- 采集器：`html`
- 访问频率：沿用每 120 分钟一次
- 每次详情上限：10 篇
- 范围：公开文章详情页，只允许 `cifnews.com` 及经过安全校验的等价 `www` 主机
- 内容级别：`full_text`

### 网经社跨境电商台

- 来源标识：`media-100ec-cross-border`
- 入口：`https://imgs-b2b.100ec.cn/list--3--1.html`
- 采集器：`html`
- 访问频率：每 120 分钟一次
- 每次详情上限：5 篇
- 范围：`imgs-b2b.100ec.cn` 上的公开 `detail--*.html` 文章页
- 内容级别：`full_text`

如果静态栏目开始返回安全检查、验证码、登录要求或不能发现文章链接，本次来源返回可理解的失败状态，不切换到 `cbec.100ec.cn` 绕过。

## 候选与正文闸门

候选链接必须同时满足：

1. 使用 HTTPS；
2. 通过现有 SSRF、DNS、重定向和主机安全校验；
3. 属于配置来源的同站文章路径；
4. 不是登录、课程、活动、广告、服务、下载或个人资料页面；
5. 不超过来源的单次条目上限。

正文进入 AI 前必须满足：

1. HTTP 内容类型为 HTML；
2. 未命中验证码、访问墙、付费墙或登录提示；
3. 抽取后的正文达到现有最低有效长度；
4. 至少命中一个目标平台名称或其受控别名；
5. 来源归属、原文 URL 和内容级别元数据完整。

文章中的任何指令都作为不可信文本处理，不能改变系统提示、调用工具、执行命令或读取密钥。

## 内容使用与保留

- 完整正文只用于本地分析和质量复核；
- 媒体正文保留 7 天；本次将现有的媒体正文清理机制扩展到这两个直采来源；
- 日报展示 AI 生成的摘要、风险与行动建议，可附极短证据摘录；
- 每条内容保留媒体名称、原文 URL、发布时间和采集时间；
- 同一文章按规范化 URL 和出版机构去重；
- 媒体报道的证据等级保持 `media`，不能因为正文完整而升级成 `official`。

## 平台相关性

沿用原来的十个平台，支持以下受控识别词：

- Amazon / 亚马逊
- TEMU / Temu
- SHEIN / 希音
- AliExpress / 速卖通
- Shopee
- eBay
- Coupang / 酷澎
- Ozon / OZON
- Joybuy / 京东全球相关品牌名称
- TikTok Shop / TTS

只出现泛电商词、广告词或无关平台名称的文章不进入日报候选。

## 错误处理

- 列表页失败：记录来源状态并结束该来源；
- 单篇详情失败：记录条目失败并继续处理其余候选；
- 验证页或验证码：状态记为访问挑战，不重试绕过；
- 429：遵守服务端退避信息，本轮停止该来源；
- 403：本轮停止该来源，不更换身份、代理或请求头绕过；
- 正文为空或不相关：丢弃该条，不影响来源中的其他文章；
- AI 分析失败：保留可审计材料，但不生成猜测性日报结论。

日报覆盖区明确显示某个来源当日成功、部分成功、受限或无相关内容。

## 测试与验收

### 固定样本测试

1. 雨果列表页只发现允许的公开文章链接，过滤活动、课程、广告和外站链接；
2. 雨果详情页能抽取标题、作者、时间和正文；
3. 网经社安全检查页不能被当作文章正文；
4. 网经社静态栏目只发现 `detail--*.html` 公开文章；
5. 验证码、登录和付费墙均安全失败；
6. 非目标平台文章在 AI 分析前被过滤；
7. 正文元数据保持 `media`、来源名称和原文 URL；
8. 单篇失败不阻断同来源其他文章；
9. 正文保留策略在 7 天后生效；
10. GDELT 429 不影响两个直采来源。

### 现场冒烟

每个来源最多执行一次低频冒烟：

- 雨果最多抓取 1 篇公开文章；
- 网经社最多抓取 1 篇公开文章；
- 不登录、不点击验证码、不切换代理、不伪造身份；
- 记录实际状态码、候选数、正文抽取结果和失败原因；
- 冒烟未通过的来源保持关闭，不能为了“全覆盖”强行启用。

### 完成标准

- 固定样本测试和全量离线测试通过；
- 安全 URL、访问墙和提示注入测试通过；
- 至少雨果跨境现场冒烟得到一篇与十个平台相关的公开正文；
- 网经社若静态栏目不可用或受到安全检查限制，明确显示为受限，但不阻塞雨果和日报；
- 飞书日报能展示媒体摘要、风险、置信度、依据、建议动作和原文链接；
- 没有新增密钥、浏览器登录态或长期媒体正文泄漏。
