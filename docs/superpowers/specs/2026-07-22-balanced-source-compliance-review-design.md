# 17 个候选来源平衡开放审核设计

日期：2026-07-22
状态：待用户复核书面规格

## 目标

审核当前登记表中 17 个 `pending_review` 官方来源。在发布方没有明确禁止自动访问时，允许对公开页面进行低频、可停止、可追溯的采集；明确禁止、要求事先授权或需要绕过访问边界的来源不得启用。

审核仅覆盖用户指定的 Amazon、Shopee、eBay、Coupang、Ozon 和 Joybuy 候选来源。已经是 `allowed`、`denied` 或 `authorization_required` 的其他来源不在本轮改动范围内。

## 审核口径

每个来源分别检查官方入口、官方条款、`robots.txt`、登录边界、重定向和真实 HTTP 响应。搜索摘要、第三方博客和一次偶然成功的请求不能单独作为审核依据。

### 允许

来源同时满足以下条件时，可改为 `allowed`：

1. 页面无需登录、用户提供的 Cookie、验证码、付费订阅或账号授权即可访问；
2. 官方条款未明确禁止自动抓取、机器人访问、复制或本项目所需的有限内容处理；
3. `robots.txt` 未明确禁止目标路径；缺失或无法取得 robots 不能单独视为授权，但在条款无禁止且页面公开时不自动否决；
4. 访问不需要更换代理、伪造浏览器身份、绕过地区限制或突破其他技术限制；
5. 单来源真实抓取测试成功，响应类型、重定向和页面结构符合登记配置。

审核先使用不带登录态的独立单请求探测验证公开可达性。证据满足允许条件后，来源设置为 `allowed + enabled` 并立即执行一次生产采集器的单来源验收；验收失败则在同一批变更中恢复为 `pending_review + disabled` 或更严格状态，不留在自动调度中。

正式启用后的初始抓取间隔保持 120 分钟，单次候选数量不超过 20。只保存生成情报所需的正文、标题、时间、来源归属和原文链接，不下载图片、附件、评论、用户资料或登录后内容。

### 需要授权

出现以下任一情况时改为 `authorization_required + disabled`：

- 条款要求事先书面许可、API 授权或平台账号；
- 页面本身需要登录或有效会话；
- 公开页面只是登录入口，无法在未授权状态取得目标内容。

### 禁止

条款或 `robots.txt` 明确禁止目标自动访问，或真实访问要求绕过验证码、封锁、付费墙、地区限制时，改为 `denied + disabled`。

### 证据不足

如果官方条款互相冲突、目标路径归属不明，或网络故障导致无法判断，保持 `pending_review + disabled`。网络失败不能被解释为允许，也不能仅凭一次失败判定禁止。

## 运行时保护

- 沿用域名级速率限制、响应体大小限制、DNS/重定向安全检查和禁止使用登录态的现有边界；
- 单个来源先执行一次人工触发的真实抓取，成功后才允许调度器运行；
- 401、403、验证码、登录跳转或跨发布方异常重定向立即停止本次采集并进入复核；
- 429 和临时 5xx 使用有限退避，不通过提高频率、代理或伪造身份绕过；新增运行时熔断，在连续失败达到阈值后暂停该来源，并在健康状态中标记为需复核；版本控制内的合规结论仍只由人工审核修改；
- 任一来源失败不得阻塞其他来源或飞书机器人。

## 证据记录

每项结论写回 `src/commerce_agent/sources/public_sources.yaml`：

- `reviewed_at`：本次实际复核日期；
- `terms_url` 和 `robots_url`：发布方的一手证据地址；
- `compliance_notes`：说明公开性、明确禁止或授权要求、robots 结果、重定向和真实抓取结果；
- `compliance` 与 `enabled`：必须与结论一致。

审核报告另行记录逐来源结论和可点击的一手证据链接。无法验证的事项明确标记为“未验证”，不使用推测性结论。

## 验证方案

1. 先更新测试期望并确认测试因旧状态而失败；
2. 修改来源登记表，使测试通过；
3. 运行来源登记、合规策略、HTTP 安全和采集服务测试；
4. 运行 `sources list`，确认只有 `allowed` 来源能启用；
5. 对每个新允许来源分别执行一次真实抓取，不并行轰炸同一域名；
6. 检查数据库中的运行状态、采集数量、错误码和原文归属；
7. 运行完整测试与静态检查；
8. 重启本地机器人，确认采集与情报调度器正常启动。

## 验收标准

- 17 个来源均有基于一手证据的明确结论；
- 没有登录、验证码、付费墙或绕过访问控制行为；
- 明确禁止或要求授权的来源保持禁用；
- 只有条款无明确禁止、robots 未禁止且真实抓取成功的公开来源才启用；
- 新启用来源具有原文链接、来源归属、低频限制和失败停止能力；
- 完整测试和静态检查通过，机器人仍保持单实例运行。

## 非目标

- 本轮不审核 TEMU、SHEIN、AliExpress、TikTok Shop 或行业媒体的既有非待审状态；
- 不申请平台授权，不使用用户账号，不接收账号密码或 Cookie；
- 不增加代理池、验证码破解、浏览器指纹伪装或其他绕过机制；
- 不把 `robots.txt` 当作内容版权许可或法律意见。
